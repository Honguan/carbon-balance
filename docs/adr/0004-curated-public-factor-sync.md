# ADR-0004：受控公開係數同步

- Status: Accepted
- Date: 2026-07-26

## Context

盤查人員需要定期取得公開碳足跡係數，同時保留手動新增與更新能力。外部資料可能調整、缺少本系統受控單位，且不得直接改變既有計算結果。

## Decision

- 第一個受控來源採環境部環境資料開放平臺 `CFP_P_02`。
- 部署的單次 migration 工作預設為當時已存在的各組織同步一次；具係數管理權限的使用者亦可手動觸發。頁面讀取與瀏覽器重新整理不會更新資料。
- 自有 API Key 只由環境變數提供，不存入資料庫、原始碼或稽核內容；未設定時，從政府資料開放平臺詮釋資料解析目前的官方 JSON 公開下載網址。
- 只匯入能對應受控單位的非負係數；無法對應的資料計入略過筆數。
- 來源依匯入日期由新到舊取得；同一名稱、單位與機關只保留最新紀錄，超過單次頁數上限時整批拒絕。
- 環境部同步資料免人工審查，直接建立已發布版本；更新時撤回同一係數的前一已發布版本，但不重算或改寫歷史計算。升級舊資料時只啟用具系統產生來源指紋的同步草稿，手動草稿與人工撤回版本維持原狀。
- 每筆外部原始紀錄由系統自動保存 SHA-256、資料集版本、來源網址與授權識別。
- 每個組織的同步完成結果保存新增、啟用舊草稿、未變更與略過筆數的稽核事件；外部服務錯誤會讓部署工作失敗，不回傳假成功。
- 手動新增與更新仍建立待審查草稿，使用者不需輸入原始文件 SHA-256；現行已發布版保留至更新草稿核准發布，再於同一交易撤回。
- 盤查分頁只能查詢與選用已發布係數；新增、同步、審查與手動更新集中在係數資料庫頁。

## Consequences

- 公開資料更新可追蹤且可立即選用，手動係數維持審查治理，兩者皆不破壞不可變計算。
- 可選擇設定自有環境部 API Key；未設定時會額外依賴政府資料開放平臺詮釋資料服務。
- 公開資料若出現新單位，需先擴充並審查受控單位目錄，該筆資料才可匯入。
- 全新資料庫尚無組織時沒有合法的係數所有權，部署工作只記錄零組織摘要；建立組織後需由係數資料庫手動同步。
